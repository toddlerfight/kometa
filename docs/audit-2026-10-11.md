# Efficiency and dead-code audit — 2026-10-11

Baseline: tag `checkpoint-2026-10-11` (6802940). Seven read-only reviews (DB, request paths,
background jobs, outside services, dead Python, web frontend, YondeB) plus local measurements
against a copy of the production DB (7,371 books, 803 series). Numbers are local (no NAS);
on the live box every filesystem check below is an SMB round trip.

## Status (end of 2026-10-11)

- **Wave 1 — done**, plus two finds made while deploying it: SQLite connections are
  kept per thread (open/close was 295 ms a cycle on ginbako's VM-shared folder), and the
  reader no longer holds web workers on share reads. Then the real reader fix: the
  library is mounted over **NFS** (the OrbStack pass-through of the SMB mount read at
  0.1–3 MB/s).
- **Wave 2 — done** except #12 (share back-off) and #19 (local CBZ build), dropped
  because NFS removed the cost they addressed.
- **Wave 3 — done** except #25's client-side tab rendering (the series request is ~30 ms
  now; the scroll-restore bug in it is fixed) and #27 (covered by the lazy strip).
- **Wave 4 — done**: ~400 lines of dead Python (legacy Newznab path, Komga leftovers,
  five unused routes, small helpers, the Komga cover-version join), `_toggleBookFav`, the
  dead On Deck / reading-list CSS. Kept: test-only status helpers (`covers.backlog`,
  `record.backlog`, `images.store_size`), `komga_import.py` (your call), the orphan cache
  tables (data, not code). `remove_series` now clears what hangs off a series.
- **YondeB** items moved to `~/code/yondeb/LATER.md`.
